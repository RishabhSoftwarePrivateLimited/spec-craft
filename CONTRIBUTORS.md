# Contributors

Everyone who's helped build `speccraft`, in three tiers — open-source contributors welcome at
every tier, no domain restriction (unlike `MAINTAINERS.md`, which is limited to Rishabh Software Private Limited identities).

- **Members** — sustained core development.
- **Advisory** — design/direction guidance without necessarily shipping code.
- **Community** — everyone who's sent a merged PR.
