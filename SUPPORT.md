# Support

- **Questions** ("how do I...", "does this support...") → open a [GitHub Discussion](https://github.com/RishabhSoftwarePrivateLimited/spec-craft/discussions).
- **Bugs** (something is broken) → open an [Issue](https://github.com/RishabhSoftwarePrivateLimited/spec-craft/issues) using the bug report template.
- **Feature requests** → open an Issue using the feature request template.
- **Security vulnerabilities** → see `SECURITY.md` — do not use Discussions or public Issues for these.

Check `docs/faq.md` and `troubleshoot/README.md` first — most common questions are already answered there.
