# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately — **do not** open a public GitHub issue.

Email: `sandeep.prajapati@rishabhsoft.com`

Include:
- A description of the vulnerability and its impact
- Steps to reproduce
- The version of `@rspl/speccraft` affected

We'll acknowledge your report and follow up with next steps. Once a fix is released, it'll be noted in `CHANGELOG.md` and, for anything user-impacting, called out in the GitHub Release notes.

## Supported Versions

Only the latest published version on npm is supported. Please upgrade (`npx @rspl/speccraft@latest`) before reporting an issue that may already be fixed.
